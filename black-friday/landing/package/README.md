# Black Friday 2026 · лендинг для разработчиков

Промо-страница Black Friday для newserverlife.com: 5 лет гарантии на выбранные серверы Dell и HPE.
Чистый HTML, CSS и JavaScript без зависимостей. React не нужен, сборка не нужна.

Демо: https://denswor.github.io/nsl-experiments/black-friday/landing/

## Что в архиве

```
light.html               светлая версия — основная
dark.html                тёмная версия (тот же контент, другие фоны поколений и бенто)
css/nsl-ds.css           NSL Design System: токены целиком + стили только тех компонентов, что есть на странице
css/light.css            стили светлой страницы (общие правила + секции)
css/dark.css             стили тёмной страницы
js/bf-landing.js         интерактив, исходник с комментариями
js/bf-landing.min.js     то же, минифицировано (подключено в страницах)
assets/server-r740xd-lit.webp   фото сервера для hero и финального блока
CHANGELOG.md
```

Шрифты: IBM Plex Sans, IBM Plex Mono и Montserrat 900 из Google Fonts (ссылка в `<head>`). Если на сайте шрифты свои, ссылку можно убрать.

## Как устроена страница

В каждой странице две вёрстки одного и того же контента:

- `.bf-board--d` — десктоп;
- `.bf-board--m` — мобильная.

Переключение чистым CSS на 720 px (`@media (max-width: 719px)`), отдельная мобильная ссылка не нужна. Стили каждой вёрстки ограничены её обёрткой, они не пересекаются.

Порядок секций: шапка → hero → Warranty Terms → Eligible Generations (аккордеон) → What 5 year means / How It Works / For Business → FAQ → финальный CTA с Terms → футер.

Сетка и контейнер по DS: контейнер 1170 px (`--bf-container`), от 1680 px — 1530 px и широкий футер. Фоны секций тянутся на всю ширину.

Ниже 1230 px десктопная вёрстка уменьшается целиком (CSS `zoom`), отдельной планшетной вёрстки пока нет. Это место для доработки: планшет 720–1229 px.

### Шапка и футер

Шапка (`.nsl-header`, `.nsl-mshell`) и футер (`.nsl-footer`) — разметка компонентов DS, вставлена для демо. На сайте используйте шапку и футер шаблона. Нужное поведение шапки на лендинге:

- десктоп: видна целиком, при прокрутке градиентная полоса (40 px) уезжает, белая часть закреплена — `position: sticky; top: -40px`;
- мобильная: закреплено мобильное меню — `position: sticky; top: 0`.

Правила есть в `css/*.css`, блок «Fixed headers».

## JavaScript

`js/bf-landing.min.js` подключён с `defer` перед `</body>`. Работает по data-атрибутам, без глобальных переменных:

| Атрибут | Что делает |
|---|---|
| `[data-bf-toggle]` | кнопка строки аккордеона поколений: класс `is-open` на родителе и `aria-expanded` |
| `[data-bf-acc]` | обёртка FAQ (DS Accordion): плавное открытие и закрытие ответов |
| `[data-bf-hero]` | секция hero: подсветка знака идёт за курсором и пальцем |

**Подсветка знака NSL.** Без курсора свет сам ходит по контуру (цикл 9 с), с курсором или пальцем — следует за ним. В разметке у градиента `spotIdle` есть SMIL `<animate>` — это запасной вариант, если JS не загрузится. При запуске скрипт заменяет обводку на мягкое пятно под маской, вырезанной по контуру знака: Safari не перерисовывает обводку при изменении градиента, а движение пятна перерисовывает везде. С `prefers-reduced-motion` свет стоит на месте, анимации FAQ отключены.

**События** для аналитики: `CustomEvent('nsl-bf')` на `document` и `window.dataLayer`:

- `bf_view` — страница открыта (`layout: desktop | mobile`);
- `bf_gen_toggle` — открыта или закрыта строка поколения;
- `bf_faq_open` — открыт вопрос FAQ;
- `bf_cta_click` — клик по кнопке или карточке товара.

## Что заполнить перед запуском

- Цены в карточках: `[PRICE]`. Фото серверов: у карточек сейчас плейсхолдер.
- Ссылки: у карточек, кнопок «Shop Gen … servers», Request a Quote, Configure a Server и Request Expert Help стоит `#`.
- Модели в поколениях подобраны по линейкам, сверить с реальным ассортиментом акции.
- Иконки `arrow-down` и `arrow-up` (Feather) в DS-бандле сайта отсутствуют. В этой разметке иконки уже вшиты как SVG, но в DS их нужно добавить.

## Как пересобрать

Источник — доски на холсте Claude (`src/*.dc.html` в репозитории nsl-experiments). Сборка: `npm run build` в `black-friday/landing/`. Она рендерит компоненты DS в статическую разметку и пишет демо-страницы и этот архив.
