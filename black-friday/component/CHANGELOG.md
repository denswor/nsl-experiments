# Changelog

## 1.1.0 — 2026-11-13

- Подсветка края работает в Safari. Safari не перерисовывает обводку, когда меняется её градиент (ни через SMIL, ни из скрипта, и особенно через `<use>`). Теперь при запуске скрипт пересобирает свет: мягкое пятно ездит под маской, вырезанной по контуру знака. Вид, траектория и скорость те же. SMIL в разметке остался запасным вариантом на случай, если JS не загрузился.
- Цикл подсветки идёт через `requestAnimationFrame` только пока hero на экране и вкладка активна. С `prefers-reduced-motion` блик стоит и двигается только за курсором.
- Тексты по умолчанию под текущую акцию: даты Nov 16 – 30, лид про 5 лет гарантии, «Offer ends November 30, 2026».

## 1.0.0 — 2026-11-11

Первая версия.

- Hero Black Friday (вариант C) на чистом HTML, CSS и JS: тёмная полоса с радиальным фоном, знак NSL с подсветкой края, одна CTA (DS Button).
- Подсветка идёт за курсором, на телефоне за пальцем; без курсора блик обходит контур сам, на паузе вне экрана и при `prefers-reduced-motion`.
- Фото сервера не шире 1440 px. На телефоне оно стоит полосой между текстом и кнопкой.
- Include для Bitrix с настройками текстов через `$NSL_BF`, статический сниппет, демо.
- События `view` и `cta_click` (CustomEvent `nsl-bf` и `window.dataLayer`).
