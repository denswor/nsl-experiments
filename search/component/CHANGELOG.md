# Changelog

## 1.0.0 — 2026-11-11

Первая версия.

- Predictive search под любым полем с `data-nsl-suggest`: группы Server models, Chassis, Storages, Articles; подсветка каждого слова запроса; x = х; клавиатура и ARIA combobox; отмена устаревших запросов и кеш.
- «Show 10 more» на телефоне: догружает следующую страницу `search.page` и дописывает строки, обновляет счётчик и компактную пагинацию.
- Шаблон `search.page` «nsl» на разметке NSL DS: строки товар / статья / страница, пагинация ссылками, карточка помощи.
- Эндпоинт подсказок `search-suggest.php` для Bitrix (CSearch по группам инфоблоков, кеш 10 минут).
- `dist/nsl-search.css`: токены и только нужные странице компоненты DS.
- В комплекте `nsl-ask` 1.1.0 с короткой формой `variant: 'simple'`.
