# Changelog

## 1.0.0 — 2026-11-16

Первая версия меню каталога Black Friday для разработчиков.

- Меню на весь экран под шапкой, свой скролл, контакты прижаты к низу. Прокрутка страницы не блокируется.
- Тёмная тема только у меню (`.nsl-catmenu--bf`): подсветка за курсором, градиентные акценты, белые логотипы вендоров, баннер Black Friday в строке брендов.
- Анимация A «Шторка»: раскрытие сверху вниз с каскадом, переключение брендов и категорий по оси X, короткое закрытие. Reduced motion — кроссфейд.
- Вкладки брендов Plex Mono 700, текущий бренд в primary.
- Бестселлеры убраны.
- Бейджи Sale и скидки — вариант 4: Sale белым на red-700, скидка белым на green-700.
- Широкий контейнер 1530 px от 1680 px.
- Без React и без сборки: HTML, CSS, один JS-файл без зависимостей.
